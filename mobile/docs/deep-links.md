# Deep Link Routes

- `planyourtrip://invite/:token` -> `mobile/app/invite/[token].tsx`
- `planyourtrip://share/:shareId` -> `mobile/app/share/[shareId].tsx`
- `planyourtrip://planner/:tripId` -> `mobile/app/planner/[tripId].tsx`

These routes align with web invite/share semantics and support collaboration entry points.
